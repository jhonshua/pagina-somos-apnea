# Somos Apnea 🌊🇻🇪

> **Libertad en una respiración** — Escuela de apnea deportiva en Venezuela.

Página web oficial moderna, inmersiva y de alto impacto visual desarrollada con **React**, **Vite** y **Tailwind CSS**, diseñada para reflejar la belleza de las aguas venezolanas y la disciplina del buceo a pulmón libre.

---

## 🚀 Tecnologías

* **React 18**: Arquitectura de componentes interactivos y modulares.
* **Vite**: Entorno de desarrollo ultrarrápido y empaquetador moderno.
* **Tailwind CSS**: Estilos avanzados, diseño responsive y efectos visuales (*Glassmorphism*, iluminación coral y paleta oceánica).
* **Lucide React**: Iconografía minimalista.
* **TypeScript**: Tipado seguro y escalable.

## 📂 Estructura del Proyecto

```
pagina-somos-apnea/
├── public/
│   └── hero-bg.png             # Arte submarino de alta resolución
├── src/
│   ├── assets/                 # Recursos gráficos
│   ├── components/
│   │   ├── Navbar.tsx          # Barra de navegación flotante con glassmorphism

│   ├── index.css               # Estilos globales y utilidades personalizadas
│   └── main.tsx                # Punto de entrada de la aplicación

└── vite.config.ts
```

## 💻 Comandos de Desarrollo

### Instalar dependencias:
```bash
npm install
```

### Iniciar servidor de desarrollo local:
```bash
npm run dev
```
Abre en tu navegador: [http://localhost:5173](http://localhost:5173)

### Compilar para producción:
```bash
npm run build
```
